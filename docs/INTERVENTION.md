# 人类介入

## 当前现实状态

引擎层已经支持这些接口：

- `overrides`
- `world_edits`
- `inject_events`
- `on_phase_done`

但当前对外的 `ConsoleDriver` 仍然是简化版，只暴露：

- 玩家每回合手动输入行动
- `/a` 让该轮玩家角色自主行动
- `/q` 退出

也就是说，介入能力在引擎 API 已有挂点，在产品层 UI 还没有重新完整接回来。

## 介入点如何理解

### 步前

- 改玩家/NPC 的本轮意图
- 改世界状态
- 注入世界事件

### Simulation 后

- 审核结构化结算结果
- 强制补充导演指令
- 手动修正状态更新

### Rendering 后

- 覆盖本轮显示给玩家的文字
- 保留底层状态不动，只改表现层

## 与新三阶段的关系

在旧模型里，人类介入经常意味着“直接改 GM 的输出”。  
在新模型里，最好把介入分成两类：

- 改状态或改结算：属于 `Simulation`
- 改给玩家看的文字：属于 `Rendering`

这也是后续恢复高级导演式交互时应遵守的边界。
